# Design do Site de Referência - Day R Price

## Tema Visual
- Tema escuro (dark theme) com fundo azul escuro/marinho
- Header com título "TERMINAL DE COMÉRCIO SOBREVIVENTE" em laranja/amarelo
- Subtítulo "Day R Survival - Preços de Mercado" em cinza claro
- Fundo principal: azul muito escuro (#0f172a ou similar)
- Cards/seções com fundo ligeiramente mais claro
- Tabela com fundo escuro e linhas alternadas
- Botões coloridos (amarelo, verde, roxo)
- Tabs com ícones emoji para categorias
- Cores: laranja/amarelo para títulos, verde para ações positivas
- Fonte sans-serif
- Bordas sutis em tons de cinza/azul

## Estrutura
- Header com logo + título + subtítulo + taxa de câmbio
- Barra de busca
- Botões de ação (Guia, Reportar, Calculadora, Editar)
- Abas de categoria com ícones
- Tabela principal com dados
- Badge "Made with Manus" no canto
