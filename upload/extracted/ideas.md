# Banco do Clã - Day R Survival

## Design do Site de Referência
O site de referência (Day R Price) possui um design de terminal/survival com tema escuro, cores laranja/amarelo para títulos, fundo azul-marinho escuro, tabela com dados organizados, e botões coloridos. Vou replicar esse estilo visual.

## Abordagem Escolhida: "Terminal de Sobrevivência"

### Design Movement
Inspirado no visual do jogo Day R Survival e do site de referência - um painel de controle estilo terminal/painel militar com tema escuro e acentos em cores vibrantes (laranja, verde, amarelo).

### Core Principles
1. **Tema Escuro Terminal** - Fundo escuro com elementos em cores vibrantes (laranja, verde, amarelo)
2. **Informação Clara e Direta** - Tabelas organizadas, dados legíveis
3. **Navegação por Abas** - Como o site de referência, sistema de tabs para cada seção
4. **Acentos Coloridos** - Verde para entradas/lucro, vermelho para saídas/perda, amarelo/laranja para títulos

### Color Philosophy
- Fundo principal: Azul-marinho muito escuro (#0f172a)
- Cards/seções: Azul escuro com bordas sutis (#1e293b)
- Títulos: Laranja/Amarelo (#f59e0b, #eab308)
- Ações positivas: Verde (#22c55e)
- Ações negativas: Vermelho (#ef4444)
- Texto principal: Branco/Cinza claro (#e2e8f0)
- Bordas: Azul escuro (#334155)

### Layout Paradigm
- Header fixo com título e navegação por abas
- Conteúdo principal com tabelas e formulários
- Cards para formulários de cadastro
- Tabela responsiva com scroll horizontal
- Layout similar ao site de referência com tabs de categoria

### Signature Elements
1. Header com título em laranja estilo terminal
2. Abas com ícones para cada seção
3. Tabelas escuras com linhas alternadas e cores para valores
4. Badges coloridos para status (pendente, pago, atrasado)

### Interaction Philosophy
- Formulários em modais/dialogs para registro
- Feedback visual com toasts (sonner)
- Transições suaves entre abas
- Hover effects sutis nas tabelas

### Animation
- Transições de aba rápidas (150ms)
- Entrada de cards com fade-in leve
- Botões com scale on active
- Tabelas com hover row highlight

### Typography System
- Títulos: Fonte bold, cores vibrantes
- Corpo: Fonte legível, cinza claro
- Valores numéricos: Fonte mono para alinhamento

### Brand Essence
"Banco do Clã - Gerenciamento inteligente de recursos para sobreviventes do Day R Survival"
Adjetivos: Organizado, Transparente, Estratégico

### Brand Voice
- Direto e informativo
- Termos do jogo (Moeda Amaldiçoada, itens, trocas)
- Exemplos: "Novo empréstimo registrado", "Lucro de 150 itens contabilizado no caixa"

### Wordmark & Logo
Ícone de engrenagem (⚙️) com moeda - estilo terminal industrial

### Signature Brand Color
Laranja vibrante (#f59e0b) - cor do terminal de comércio sobrevivente

## Abas do Sistema
1. **Início** - Dashboard com resumo
2. **Empréstimos** - Registro e gestão de empréstimos + calculadora
3. **Investidores** - Registro de membros investidores
4. **Trocas** - Tabela de trocas + registro + calculadora
5. **Caixa do Banco** - Entradas e saídas automáticas
6. **Doadores** - Registro de doadores
